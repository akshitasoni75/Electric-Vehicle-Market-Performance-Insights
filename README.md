
# Electric Vehicle Market Performance & Insights

## Project Overview
This project focuses on analyzing the Electric Vehicle (EV) market to understand sales performance, manufacturer market share, battery technologies, vehicle range, and emerging market trends.

Using data analytics and visualization tools, the project transforms EV market data into meaningful insights through an interactive dashboard and web application.

## Technologies Used
- **Tableau Public** – Interactive dashboards and data visualization
- **Python** – Data processing and Flask integration
- **MySQL** – Database management and data storage
- **Flask** – Web application development
- **HTML/CSS** – Website structure and design

## Key Features
- Analysis of EV sales and market performance
- Manufacturer market share comparison
- Battery capacity and vehicle range analysis
- Category-wise sales insights
- Interactive Tableau dashboard and story
- Web-based dashboard integration

## Project Objective
To explore electric vehicle market trends and provide useful insights that support data-driven understanding and decision-making.
